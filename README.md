# 🛒 Store Management System

A simple **command-line Store Management System** built with Python. This project allows users to manage products, track inventory, process purchases, and monitor total sales through an interactive menu.

This project was developed as a Python practice project to strengthen my understanding of functions, dictionaries, loops, conditional statements, and program flow.

## ✨ Features

- 📦 **Show Products** — Display product IDs, names, prices, and available stock.
- ➕ **Add Products** — Add new products with unique IDs.
- 🔍 **Search Products** — Find products by name.
- 🛍️ **Buy Products** — Process purchases and calculate the total price.
- 📊 **Manage Inventory** — Increase stock quantities and check product availability.
- 💰 **Track Sales** — Keep track of total sales during the program session.
- 🔄 **Interactive Menu** — Navigate between features using a menu-driven interface.

## 🚀 Getting Started

### Prerequisites

- Python 3 installed on your computer.

### Installation

1. Clone the repository:

```bash
git clone https://github.com/narges-developer/store_management_system.git
```

2. Navigate to the project directory:

```bash
cd store_management_system
```

3. Run the Python file:

```bash
python "09 - Store management system functions.py"
```

## 💻 How to Use

After running the program, select an option from the interactive menu:

| Option | Action |
|:---:|---|
| 1 | Show Products |
| 2 | Add Product |
| 3 | Search Product |
| 4 | Buy Product |
| 5 | Add Stock |
| 6 | Show Total Sales |
| 7 | Exit |

The program starts with two sample products: a keyboard and a mouse. You can add products, update inventory, and make purchases while the program is running.

## 📌 Current Limitations

- Product data is stored in memory and resets when the program exits.
- Sales information is not saved between sessions.
- User input is expected to be valid; non-numeric input may cause an error.
- The application runs in the terminal and does not have a graphical interface.
